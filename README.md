# PyGame-spill
spill i pygame

tema:
Du er en alien som skal kidnappe mennesker for å sloss i ulovlige menneske fights fordi du mistet alle pengene dine til gambling

wincon:
vinne over alle de andre aliensa og komme deg ut av gjeld

game mechanics:
turned based combat
menneske kidnapping 



jeg ønsker å få til å lage smooth healthbar


jeg skal få bildene og karakterene til å vises å funke når du slåss
og fienede

gjøre ferdig kombineringen

fiske bakgrunnene 

fikse hitboxen

plukke opp karakterene
